The Lone Star State

An informative website about the state of Texas. Completed in 2026.

Project Summary

A website overview of the state of Texas with subpages about notable cities and a contact form. Javascript is used to dynamically show and hide a dropdown menu based on user input. When the mouse enters or exits the header, or when focus shifts for keyboard users, the dropdown is opened or closed as needed. The menu was challenging to implement because when focus shifted to one of the dropdown items, the menu needed to remain open. I was also concerned about the sites accessibility because of this menu, so I used the W3C validator to ensure my HTML was correct.

The page layout was modified from the initial wireframe in order to fit the content of the website better, so I created a second wireframe to reflect the new design. The layout is dynamic to a point, but some changes need to be made for it to be readable on mobile devices. I plan to continue working on this when I have time.
