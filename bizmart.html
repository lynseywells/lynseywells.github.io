Bizmart Supply Co.

A retail application built in Java. Completed in 2024.

Project Summary

This project is a three-in-one program built with Java for a fictional business; it has a POS system, a business management tool, and an online shopping page. Different features are available depending on a user. The projects goal is to provide Bizmart Supply Co a user-friendly way to manage data and conduct business both online and in-person. When the user signs in, they are presented with a different interface depending on the accounts type: either customer, employee, or manager.

Customers can search for items using keywords or SKU numbers, add them to a cart, and place a delivery order. The employee page has very similar functionality, but is designed as a traditional point-of-sale system. Employees can search item by SKU or keyword to add it to the current transaction, cancel the transaction, and create a digital receipt. Managers can access everything that employees can, and they can also generate HTML sales reports, manage account data for all account types, create discount codes, and manage product inventory.

This application relys on a local SQLite database to keep track of inventory, user information, et cetera. The program manages an open database connection and inserts/updates rows based on user input. For example, placing an order subtracts the quantity of products ordered from the products record in the database preventing other users from order more than what's currently in stock.
